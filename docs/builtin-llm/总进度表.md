## 当前生效的额度与护栏

| 项 | 值 | 怎么调 |
|---|---|---|
| 每 key 日额度 | **1000 万 token/天**(北京时间 0 点重置) | `LLM_GW_DEFAULT_DAILY_TOKENS`,或按 key 改 `saas_key.quota_daily` |
| 每分钟请求数 / 并发 | 20 / 4 | `LLM_GW_RATE_PER_MIN` / `LLM_GW_MAX_CONCURRENCY` |
| **全平台日总量熔断** | **1.5 亿 token/天**(2026-09-22 由 5000 万上调) → 402 + 中文引导 | `LLM_GW_GLOBAL_DAILY_TOKENS` |
| **一键停用** | `HUNTER_BUILTIN_LLM_ENABLED=0` → 403 + 中文引导 | 改 `.env` 一行 + restart(实测 **7 秒**),不用改代码或回滚 |
| 异常用量告警 | 单 key 单日 > 3×默认额度;或 1 小时 > 日额度 50% | `LLM_GW_ABUSE_DAILY_MULTIPLE` / `_HOUR_RATIO` |
| 可用性探针 | 每 10 分钟,连续 3 次失败告警、恢复补发 | cron `*/10 * * * *` |
