## 评审前请先看

- **会员校验不存在**:扫描、生成、字段搜索、命中日四个接口在 /api/quant/ 免登录前缀下,匿名可调;只有保存、删除、忘掉要登录。上线给会员之前要先定:哪些功能限会员、非会员看到什么、在接口层怎么拦。QX 组里标了「未实现」的用例都依赖这个方案。
- **AI 识别没有成本保护**:parse 接口匿名可用,allow_ai=true 就调用模型,没有频率或额度限制。会员放开后建议先加限额。
- **并发与上游风险未验证**:扫描实时请求非官方上游接口,没有排队与限流保护。会员人数的目标值需要产品给出,XN-005 才能定阈值。
- **触屏看不了日K**:悬停日K 只支持鼠标,手机与平板上看不到。
