## 两点说明

1. **`01`~`09` 里的接口地址是 `http://m2-mockgw:8899/v1`，那是一台本机模拟网关**
   （`scripts/setup-wizard/mock-gateway.py`，行为与真实 gemini 通道一致：带 `$schema` 的工具定义先拒、
   清洗后放行）。这么做是为了不把演示站网关的真实地址发进公开仓库。
   **成果文档里三项检测的耗时全部来自对真实网关的实测**，不是这台模拟网关 ——
   两者在 `M2-成果与测试报告.md` 的测试用例表里分得很清楚。
2. API key 输入框是 `type=password`，截图里是圆点；已保存的 key 一律只显示末 4 位。
